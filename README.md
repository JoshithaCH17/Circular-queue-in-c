# Circular Queue in C

A menu-driven implementation of a
circular queue using arrays in C.

## Features
- Enqueue
- Dequeue
- Peek
- Display
- Circular wraparound

## Concepts Used
- Queue (FIFO)
- Arrays
- Modulo operator
- Circular indexing

## How to Run

Compile:
gcc circular_queue.c -o circular_queue

Run on Windows:
.\circular_queue.exe

## Language
C
